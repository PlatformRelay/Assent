## Learnings

- tooling: under this loop's commit-then-review sequence the tasks.md tick lands in the
  follow-up record commit, not the reviewed task commit — a fresh diff-only reviewer will
  flag the missing tick as a finding unless the fanout `--target` states the ordering
  ("tick lands in the follow-up record commit"). Pre-empting it in the target costs one
  sentence.
- tooling: scratch sensor scripts outside the repo are not reproducible by reviewers; the
  diff-only leg re-derived the wording check by hand (worked, but cost it a round of
  reconstruction). For a future copy task, inlining the scratch script's diff output (or
  the script itself) in the evidence file would make the sensor reproducible.
- spec: the copied body carries two deliberate deviations from "the README's story" —
  the "Read the docs" paragraph and the Developers/Taskfile block are both dropped as
  site-irrelevant; both are justified by REQ-DOC2-S01-01's content list. They are now
  named as exclusions (A)/(C) in row 4, so a later wording-fidelity reviewer does not
  re-litigate them.
